Before running the script:

<br>

- Add "Twitch category": "directory name" pairs to CATEGORY_TO_DIRECTORY;

<br>

- (Only once) Run

```
py .\twitch_live_organizer.py --install-startup
```

to start it at Windows boot.

<br>

Use

```
py .\twitch_live_organizer.py --uninstall-startup
```

to remove it from the startup.
